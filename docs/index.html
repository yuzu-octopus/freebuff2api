Freebuff LLM Router

OpenAI-compatible gateway for Freebuff

Route any agent at localhost:8787/v1 — multi-token concurrency, session affinity, CLI identity spoofing, and live model enrichment over Freebuff's protocol.

View on GitHub

Features

OpenAI-Compatible Surface

`/v1/chat/completions` and `/v1/responses` (Responses API → chat format translation). Point any agent — Claude Code, OpenAI SDK, ai-sdk, Cursor — at localhost:8787/v1.

Multi-Token Concurrency

Each Freebuff account has a single global active session per model. The router reads comma-separated tokens from `FREEBUFF_TOKEN` and maintains an idle-slot pool — each token is an independent session slot for parallel request handling.

Session Affinity

Reuses a token that already has an active session for the requested model. Avoids session churn and preserves Freebuff's server-side context/cache for the same conversation.

Run Rotation

Agent runs rotate every 5.5 hours to stay under Freebuff's ~6-hour session expiry ceiling.

Live Model Enrichment

`/v1/models` augments the static 7-model catalog with real-time `rateLimitsByModel` and `limitedModelOffers` fetched from the Freebuff session endpoint.

CLI Identity Spoofing

Spoofs `user-agent: ai-sdk/openai-compatible/0.1.0/codebuff` and sends `codebuff_metadata.cost_mode: 'free'` to bypass the `free_mode_cli_required` gate.

Auth Gating

Optional `routerKey` protects `/v1/*` routes with `Authorization: Bearer` checking.

Architecture

The router runs entirely locally — no external services, no telemetry, no data leaving your machine except Freebuff API calls.

Important: Free mode chat is gated server-side to the official Freebuff CLI. The router spoofs CLI identity to access the free tier — use at your own risk. See PROTOCOL.md for the full reverse-engineered protocol.

Quick Start

# 1. Get your Freebuff token
export FREEBUFF_TOKEN=your_token_here

# For concurrency (optional):
# export FREEBUFF_TOKEN=token_a,token_b,token_c
bun dev

# 3. Point your agent at http://localhost:8787/v1
